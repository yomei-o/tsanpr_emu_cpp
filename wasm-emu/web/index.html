TS-ANPR — 本物のエンジンを WebAssembly で

固定値スタブではありません。実際の tsanpr.dll(46 MB) と 暗号化モデル(167 MB) を x86 エミュレータごと WebAssembly で動かし、ブラウザ内で推論します。 ライセンス指紋はこのリポジトリ同梱のオラクルから再生します。

モデル

① モデル(167 MB)をダウンロード → tsanpr-2512M.eon

モデルは大きく GitHub Pages では配信できない(Git LFS / 1ファイル100 MB 制限)ので、 GitHub から一度ダウンロードして選んでください。ファイルはブラウザ内に留まり、どこにも 送信されません。

モデルが大きいので初回は数十 MB のダウンロードと、認識に数分かかります(セッション構築が支配的)。 タブで ~1.3 GB 使います。
